# Opening names

`a.tsv` through `e.tsv` are copied unchanged from
[lichess-org/chess-openings](https://github.com/lichess-org/chess-openings) at commit
`a6189a30dc273ccb21fc2536a9a2fefd5592a67a` (2026-10-06). They are dedicated to the public domain under
CC0 1.0. The Lichess Opening Explorer takes its `opening` field from the same dataset, so these files
name positions without requesting their Explorer tables.

To update, copy the five files from a newer commit and change the commit in this file and in
`repertoire/opening_names.py`.
